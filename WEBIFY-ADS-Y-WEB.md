# Webify — prompts para los anuncios y la página

Tres bloques para pegar en ChatGPT. Venden **una sola cosa**: el Sistema
de Citas Webify. Nada de UGC, nada de contenido, nada de servicios sueltos.

## Cómo se usa

1. Chat nuevo en ChatGPT → pega el **Bloque 1** → contesta "Listo".
2. En ese mismo chat, pega el **Bloque 2** → te hace los creativos uno por
   uno. Escribe "siguiente" para pasar al próximo.
3. **Otro chat nuevo** para la web → pega el **Bloque 1**, después el
   **Bloque 3**, y debajo el código de tu página actual.

Los anuncios y la web van en chats separados. Si los juntas en un chat muy
largo, ChatGPT se pierde y empieza a olvidar las reglas.

Si ya tienes colores de marca, cámbialos en el Bloque 1 antes de pegarlo.
